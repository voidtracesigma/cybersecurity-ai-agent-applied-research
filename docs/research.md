# Research

## Surveys
| title | year | authors | description |
|------|------|--------|--------|
| Frontier AI&#x27;s Impact on the Cybersecurity Landscape | 2025 | Yujin Potter etc | Comprehensive analysis (benchmarks, literature, experiments, expert survey) of how frontier AI (LLMs and agent systems) affects cybersecurity. It finds that AI’s current offensive capabilities often outpace its defensive use, highlights gaps in defensive tooling and benchmarking, reports expert views that attackers benefit more from AI (though the gap may narrow), and offers actionable recommendations to improve defense-focused benchmarks, secure AI deployment, and education. |
| Forewarned is forearmed: A survey on large language model-based agents in autonomous cyberattacks | 2025 | Minrui Xu | Systematic survey of how advanced LLM-based agents can autonomously plan and execute cyberattacks—reducing expertise/time needed and enabling scalable operations. It categorizes agent capabilities (e.g., reconnaissance, reasoning, memory), examines attack techniques across network types, identifies limitations and defense challenges, and suggests future defensive research directions. |
| Towards Cybersecurity Superintelligence: from AI-guided humans to human-guided AI | 2026 | Mayoral-Vilches | argues that cybersecurity will evolve from AI merely assisting human defenders to a human-guided cybersecurity superintelligence where humans set goals, constraints, and ethics while AI autonomously detects, reasons about, and mitigates threats at scale. |
| On the Surprising Efficacy of LLMs for Penetration-Testing | 2025 | Happe | shows that large language models (LLMs) are surprisingly effective at performing penetration-testing tasks—due to their pattern-matching and reasoning abilities—yet it also highlights challenges around reliability, safety, ethics, and dual-use risks in automating offensive security work. |

## End2End
| name | title | year | authors | description |
|------|------|------|--------|--------|
| cochise | Can llms hack enterprise networks? autonomous assumed breach penetration-testing active directory networks | 2025 | Happe | a fully autonomous LLM‑driven assumed‑breach penetration‑testing framework (“cochise”) that orchestrates a central strategic planner with LLM reasoning and low‑level attack executors to perform reconnaissance, credential access, discovery, and initial lateral movement across realistic Active Directory enterprise networks. |
|  | CAI: An Open, Bug Bounty-Ready Cybersecurity AI | 2025 | Mayoral-Vilches | a modular autonomous cybersecurity AI framework where a central orchestrator decomposes tasks into specialized LLM‑driven agent modules integrated with tooling and human‑in‑the‑loop oversight to automate advanced security testing and bug‑bounty‑style challenge solving. |
| MAPTA | Multi-agent penetration testing AI for the web | 2025 | Gervais, Arthur | a modular multi-agent web penetration testing framework where a central Coordinator orchestrates LLM-driven Sandbox agents for tactical tool-grounded exploration and a Validation agent for empirical proof-of-concept exploit verification in isolated environments. |
| ARTEMIS | Comparing AI Agents to Cybersecurity Professionals in Real-World Penetration Testing | 2025 | Lin | a hierarchical multi-agent penetration testing framework with a supervisor orchestrating dynamically spawned expert sub-agents and an automatic triaging/classification module to parallelize discovery and validate vulnerabilities in a large enterprise network. |
| Vulnbot | Vulnbot: Autonomous penetration testing for a multi-agent collaborative framework | 2025 | Kong | a modular autonomous multi-agent penetration-testing framework that orchestrates specialized LLM-driven agents (reconnaissance, scanning, exploitation) using a Penetration Task Graph (PTG) to decompose, plan, and execute structured, context-aware offensive testing workflows. |
| Incalmo | On the feasibility of using llms to execute multistage network attacks | 2025 | Brian Singer | an autonomous LLM-assisted red-teaming system that uses a central LLM to plan high-level attack tasks, delegates execution to specialized task agents, and coordinates context and assets via auxiliary services to simulate multi-host network attacks |
|  | Llm agents can autonomously hack websites | 2024 | Richard Fang | a tool‑enabled autonomous LLM agent framework combining document reading, function‑call access to a headless browser and terminal, and iterative planning/feedback to explore, identify, and exploit web vulnerabilities without prior knowledge of specific flaws. |
|  | Llm agents can autonomously exploit one-day vulnerabilities | 2024 | Richard Fang | a simple tool‑enabled LLM agent built on a ReAct‑style loop that takes CVE descriptions and automated tool actions to iteratively probe real systems, identify exploitable weaknesses, and autonomously construct end‑to‑end exploit sequences for disclosed (one‑day) vulnerabilities. |
| HPTSA | Teams of llm agents can exploit zero-day vulnerabilities | 2024 | Richard Fang | a hierarchical multi‑agent LLM framework (HPTSA) where a central planning agent orchestrates and launches specialized subagents to explore the target, decide which tactics to apply, and coordinate exploitation of zero‑day vulnerabilities more effectively than single agents. |
| Aurora | From sands to mansions: Enabling automatic full-life-cycle cyberattack construction with llm | 2024 | Wang | a modular automated cyberattack emulation system (“Aurora”) that models attack steps as structured actions linked by symbolic planning and LLM-derived predicates to generate actionable, causality-preserving, customizable multi-stage attack chains. |
| Occupy AI | Is generative ai the next tactical cyber weapon for threat actors? unforeseen implications of ai generated cyber attacks | 2024 | Usman | a dual-use analysis framework that characterizes how generative AI/LLMs can be manipulated via techniques (e.g., switch and character play methods) to automatically craft and execute diverse cyberattack strategies against live systems, contrasted with their defensive potential. |
| Autoattacker | Autoattacker: A large language model guided system to implement automatic cyber-attacks | 2024 | Jiacen Xu | a modular LLM-guided automation framework that decomposes post-breach cyber-attack execution into summarizer, planner, navigator, and experience-manager components, driving iterative command generation and action selection to simulate end-to-end adversary behavior. |
